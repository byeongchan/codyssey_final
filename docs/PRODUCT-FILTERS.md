# 카테고리별 상세 검색

PC 주변기기·스마트폰/디지털·취미/레저·패션/스포츠 목록 위에 상세 검색을 표시합니다.

- 카테고리바의 선택 경로를 기준으로 남은 하위 분류만 드롭다운에 표시합니다.
- 대분류에서는 그룹 → 상품 종류를 선택합니다. 남성패션에서는 티셔츠·셔츠·니트 등의 상품 종류를 선택합니다.
- 남성패션 → 티셔츠로 진입하면 상의·아우터를 다시 표시하지 않습니다. 티셔츠 전체 또는 맨투맨·후드 티셔츠·카라 티셔츠와 브랜드를 선택합니다.
- 아이폰에서는 기종, 맥북에서는 에어·프로 같은 제품군을 선택합니다.
- 추가 분류가 정의되지 않은 항목은 불필요한 분류를 만들지 않고 브랜드 선택만 제공합니다.
- 가격·정렬·성별·색상·사이즈·핏·넥라인·할인 조건은 상세 검색 UI에서 제거했습니다.

분류는 카테고리바 데이터와 공유하며, 기종·추가 분류·일부 브랜드 추천은 `frontend/src/classificationFilters.ts`에서 관리합니다. 목록은 탐색용 예시이며 전체 기종이나 실시간 판매 목록을 의미하지 않습니다. 다른 기종은 상단 검색창으로 검색할 수 있습니다.

## 검색 적용

검색어를 조합할 때 같은 단어는 대소문자·공백 차이를 정리해 한 번만 반영합니다. 세부 분류를 선택하면 상위 상품명 대신 선택한 분류를 사용합니다. 예를 들어 남성패션의 바지에서 청바지를 선택하면 `남성 청바지`, 아이폰에서 아이폰 16 Pro를 선택하면 `아이폰 16 Pro`로 조회합니다. 별도로 입력한 추가 검색어는 유지합니다.

선택 중에는 요청하지 않고 **검색 적용**을 누르면 첫 페이지를 조회합니다. **조건 초기화**는 상세 선택을 지우되 카테고리바에서 선택한 경로는 유지합니다. 다른 경로로 이동하면 이전 상세 조건을 초기화합니다. 같은 조회의 다음 페이지·목록 복귀에서는 조건을 유지합니다. URL에서 상세 조건을 복원하지는 않습니다.

다나와는 분류·기종을 검색어로 반영하고, 확인된 제조사 코드가 있으면 제조사 필터를 사용합니다. 무신사는 선택 종류에 맞는 지원 category와 남성/여성 카테고리의 gender를 내부적으로 유지하고, 세부 분류는 검색어로 반영합니다. 성별을 별도로 선택하는 UI는 없습니다. 코드가 없는 브랜드는 이름 검색을 사용합니다. 검색어 기반 분류는 엄격한 상품 분류 일치를 보장하지 않습니다.

서버의 기존 필터 지원은 유지하지만 새 화면에서는 가격·정렬·옵션 조건을 보내지 않습니다. 기본 정렬을 사용합니다. 새 환경변수나 의존성은 필요하지 않습니다.

## 사용자 확인 항목

- 남성패션 → 티셔츠에서 상의·아우터 대신 티셔츠 하위 종류만 표시되는지 확인합니다.
- 아이폰 기종 드롭다운을 선택해 검색하고 다음 페이지에서도 조건이 유지되는지 확인합니다.
- 대분류 → 그룹 → 상품 종류를 바꿀 때 이전 하위 선택이 초기화되는지 확인합니다.
- 조건 초기화 이후에도 카테고리바의 남성패션·티셔츠 또는 아이폰 조건이 유지되는지 확인합니다.
- 무신사에서 티셔츠·바지·신발 등을 선택하면 요청 category도 바뀌는지 확인합니다.

사용자 요청에 따라 실행·빌드·테스트·실제 API 호출은 수행하지 않았습니다.
