# 중고 AI 구매 비서

2026-11-03 코드 기준. 초기 제목 완전 일치·48개 후보·강제 추출 양식 등 이전 설계는 [개발 이력](archive/USED-AGENT-HISTORY.md)으로 이동했습니다.

## 입력과 서버 근거

- 검색 요약: `/api/v1/me/used/agent/search/summary`, 검색 질문: `/api/v1/me/used/agent/search/messages`
- 상세 질문: `/api/v1/me/used/agent/{provider}/{productId}/messages`
- 브라우저는 검색 근거 최대 3개, 후보 ID 최대 1,200개, 질문과 최근 대화 최대 6개만 전달합니다. 가격·본문·통계는 서버가 저장된 `liveDisplayCache`에서 검증하여 읽습니다.
- 서버는 전체 검색 집계와 선택 상품을 제외한 모델/종류별 참고 집계를 구분합니다. 만료된 후보는 현재 가격 비교에서 제외합니다.
- `UsedApiEvidence`는 실제 상세 API의 제목·가격·설명·지역·상태·거래 방식·판매자 표시 정보·시각 등 제공된 필드를 사용합니다. 모델·옵션·상태·구성품 여섯 칸을 모두 필수로 채우는 답변 형식을 강제하지 않습니다. 사진 AI 판독은 수행하지 않습니다.

## 검색 분석

`UsedSearchAnalysis`는 유효한 게시 가격의 최저·평균·중앙·최고가, 중앙 50% 구간, 분포를 계산합니다. 0원/가격 미확인·판매 종료/예약·명확한 비정상 저가 등 정책상 제외 자료를 구분합니다. 낮은 가격을 모두 사기로 단정하지 않습니다.

`UsedProductGroups`는 같은 모델명끼리 묶고, 모델이 없으면 상품 종류로 분류합니다. 용량·색상까지 나누지 않습니다. 불명확하거나 여러 모델이 섞인 제목은 억지로 확정하지 않습니다. 상위 40개 그룹과 생략 수를 제공하며 선택 상품의 그룹 참고 집계는 별도로 계산합니다.

지역 통계는 가격 제외 전 고유 매물 기준이며, 중고나라·당근별 지역 제공/미제공 건수·비율과 지역 분포를 표시합니다. 당근 검색 기준 지역과 판매자가 기재한 지역은 다를 수 있습니다.

## 상세 판단

`UsedPurchaseJudgment`는 동일 모델·종류 그룹의 참고 가격대를 우선 사용합니다. 충분한 그룹 표본이 있으면 중앙 가격 구간과 비교하고, 소수 표본은 관측 범위로만 안내합니다. 엄격한 동일 조건 비교(`UsedDetailAnalysis`)와 모델 단위의 참고 가격은 별도입니다. 미확인 배송비·상태·구성 등은 추가 검토 사항으로 보여주되 확인된 근거로 참고 판단을 제공합니다. 거래 안전·총액·성능 보증으로 표현하지 않습니다.

## 저장과 최근 본 상품

`usedAgentContext.ts`는 API 주소로 구분한 localStorage에 상품별 검색 근거 ID와 후보 ID만 24시간·최대 30개 저장합니다. 원문이나 가격을 브라우저 저장값으로 신뢰하지 않습니다. 이전 sessionStorage 형식을 만료를 연장하지 않고 이전하며, 저장소를 쓸 수 없으면 메모리로 보완합니다.

최근 본 상품에서 열어도 해당 상품에 연결된 검색 근거를 우선 복원하고 다른 현재 검색 자료를 섞지 않습니다. 근거가 없거나 만료되면 상세 정보로 분석하고 재검색을 안내합니다. 최근 본 상품은 별도 최대 5개·30일 정책이므로 검색 근거가 먼저 만료될 수 있습니다. 서버는 검색 자료와 버전을 다시 검증합니다.

## 화면과 처리

- PC: 우측 고정, 높이 제한, 대화 내부 스크롤, 입력창 하단 유지
- 작은 화면: 쇼핑 도구에서 AI 구매 비서를 선택하여 패널 표시
- 검색창: 최저·평균·최고가와 분석/제외 수만 기본 표시
- 상세 분석: 별도 dialog에서 가격 분포·모델/종류·지역 선택, 모델별 접이식 상세. 모바일은 전체 화면
- 생성 완료 전에는 로딩 애니메이션과 안내를 유지합니다. 생성 실패를 완성된 답변처럼 표시하지 않습니다.
- Gemini 대기 120초·본문 처리 경과 제한 135초, API AI 요청 150초, 브라우저 240초 설정입니다. 실제 응답 시간은 실행 환경에서 확인해야 합니다.

로그인·원본 내용 반영·모델 분류·지역 미제공 비율·이상 저가 제외·직접 상세 진입·최근 본 복원·만료·모달·모바일·실제 AI 실패를 케이스별 기록합니다. 구현 설명은 테스트 성공 증거를 대신하지 않습니다. 현재 확인 범위는 [TASKS](../TASKS.md)를 따릅니다.
