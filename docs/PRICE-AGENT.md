# 다나와 AI 구매 비서

2026-11-03 코드 기준. 이전 단계별 변경 메모는 [이력](archive/PRICE-AGENT-HISTORY.md)으로 분리했습니다.

## 실제 연결

- 다나와 상세 페이지 `Danawa.tsx` → `PriceAgentChat.tsx`에서 이메일 인증 회원이 질문합니다.
- `POST /api/v1/me/danawa/agent/{productId}/messages`, `GET /api/v1/me/danawa/agent/jobs/{jobId}`를 사용합니다.
- Spring `PriceAgentController`가 저장 가격 근거·기간 이력·질문 유형·뉴스를 준비하고 FastAPI `price_agent.py`에 전달합니다.
- [구매 판단 정책](PURCHASE-DECISION-V3.md), [기간 이력](PERIOD-HISTORY.md), [뉴스 평가](NEWS-PRICE-IMPACT.md)를 함께 사용합니다. RSS는 명시적 설정 시에만 사용합니다.
- 개인화된 답변은 공용 Firestore 답변으로 저장하지 않습니다. 현재 정책과 짧은 메모리 재사용·사용자/상품별 문맥을 적용하며, 오래된 문서의 고정 질문·공용 답변 캐시 설명과 구분합니다.

## 화면

PC는 우측 고정·화면 높이 제한을 적용하고 대화 영역만 내부 스크롤합니다. 작은 화면은 공통 쇼핑 도구에서 AI 비서 또는 최근 본 상품을 선택합니다. 구매 시급성·추천 질문·일반 질문 입력을 유지합니다. 사용자/상품/근거 변경 시 대화를 초기화하며, 답변 생성 중에는 로딩 안내를 표시합니다. `scrollIntoView()`로 페이지 전체를 이동시키지 않습니다.

## 대기 시간 및 실패

Gemini HTTP 대기 120초·본문 처리 경과 제한 135초, Spring AI 요청 150초, 브라우저 개별 요청 240초, 작업 조회 전체 245초 설정입니다. 엄밀한 단일 전체 마감은 아니며 네트워크·배포 서버 제한도 따릅니다. 오류는 시간 초과뿐 아니라 인증·할당량·모델·형식 검증 실패로도 발생할 수 있습니다. 자동으로 유료 질문을 재전송하지 않습니다.

## 검증

로그인/비로그인, 가격·뉴스·사양 질문, 실패·로딩, 사용자/상품 변경, 모바일 패널을 확인합니다. 실행 검증 상태는 [TASKS](../TASKS.md)를 참고합니다. 이 문서 자체는 실사용 검증 성공 보고가 아닙니다.
