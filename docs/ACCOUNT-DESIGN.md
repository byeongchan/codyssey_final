# 내정보 디자인 적용

`로그인 베이스 코드/account-page-base`의 내정보 화면을 참고해 로그인 완료 후 계정 화면에 적용했다. 로그인·가입·가입 대기 화면의 흐름과 인증/API 처리 코드는 유지한다.

- 왼쪽 보라색 브랜드 패널과 원본 캐릭터 이미지(`frontend/public/brand/account-joopjoop.png`).
- 오른쪽 실제 표시 이름·이메일·가입일·인증 상태를 표시하는 프로필 카드.
- 기존 LiveWishlistProvider의 실제 찜 개수와 미리보기, 찜 목록/상품 상세 이동. 로딩·실패를 0개로 표시하지 않는다.
- 기존 최근 본 상품 저장소를 읽는 기기별 개수/목록. 계정 전체 활동이나 다른 기기 기록으로 표현하지 않는다.
- 계정 정보: 기본 정보·실제 권한·표시 이름 변경. 기존 이름 검증·7일 제한·API를 유지한다.
- 보안·관리: 이메일 인증 재발송/확인·비밀번호 재설정·관리자 권한 관리. 관리자 전용 표시와 서버 검증을 유지한다.
- 기존 로그아웃과 비밀번호 재인증·확인 동의를 거치는 회원 탈퇴 절차를 유지한다.

예시 활동 수·예시 상품, 서버가 지원하지 않는 관심 카테고리 저장·알림 선호 설정·작성 글 집계를 추가하지 않았다. 디자인 파일의 데모 인증·역할 변경 로직은 가져오지 않았다. CSS는 현재 테마 변수를 사용하고 데스크톱/태블릿/모바일 레이아웃을 포함한다.

사용자의 실행·테스트 방침에 따라 빌드·서비스 실행·실제 계정 변경/메일 발송·회원 탈퇴 테스트는 진행하지 않았다. 정적 코드 확인과 git diff --check를 수행했다.
