# 약관 및 개인정보처리방침 초안

문서 원문은 `frontend/src/legalDocuments.ts`에서 관리하고, 푸터의 이용약관·개인정보처리방침 버튼으로 열람합니다. 팝업은 닫기, Escape와 바깥 영역 클릭을 지원합니다. 이 변경은 약관 동의나 국외 이전 동의 수집 기능을 추가한 것이 아닙니다.

운영 주체명, 보호책임자·연락처, 시행일, 로그·삭제 표지·문맥 자료의 파기 기간, 외부 제공자 계약과 실제 처리 지역·국외 이전 근거는 확인되지 않았으므로 초안에 표시했습니다. 실제 운영 정보와 정책을 확정한 뒤 해당 항목과 문서 상태를 함께 갱신해야 합니다. Firebase의 프로젝트 위치만으로 Gemini 등 모든 처리의 국가를 확정할 수 없습니다.

작성 시 회원 인증·찜·검색 기록·AI 문맥·개인별 답변 메모리·탈퇴 코드를 확인했습니다. 문맥의 30분 유효기간과 답변의 5분 재사용 기간을 물리적인 즉시 파기로 설명하지 않았습니다. 탈퇴 후 UID에 연결된 삭제 상태 표지가 남는 현재 구현도 구분했습니다.

관련 공식 근거:

- [개인정보 보호법 제30조: 처리방침의 수립 및 공개](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1032645945)
- [개인정보 보호법 국외 이전 관련 조문](https://law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1020398611)

확인 방법: 푸터에서 이용 안내 하나를 연 뒤 다른 항목을 누르면 이전 항목이 접히는지 확인합니다. 두 정책 버튼에서 문서 전환·긴 내용 스크롤·모바일 폭·Escape 닫기·닫은 뒤 버튼으로 초점 복귀를 확인합니다. 실행 및 브라우저 검증은 사용자가 진행합니다.
