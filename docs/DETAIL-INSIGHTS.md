# 상품 상세 가격 흐름·리뷰 요약

## 적용 내용

사이트2의 상세 페이지에 있는 두 열 카드(가격 흐름 / 리뷰 AI 요약), 민트색 가격 그래프, 장단점 언급 막대 디자인을 현재 React 상세 화면에 적용했다. 목업의 고정 할인율·만족도·후기 분석 건수는 사용하지 않는다.

모바일은 한 열이며 기존 테마 변수로 다크 모드도 따른다. Spring API 계약 버전은 0.22.0, Node 수집기 계약은 0.4.0, FastAPI 계약은 0.4.0으로 갱신했다.

## 가격 흐름

- 상세 진입 시 POST `/api/v1/danawa/price_history`에 `{ "productId": "선택한 상품 코드" }`를 전송한다. 로그인은 필요하지 않다.
- Spring → Node 내부 수집기 → `POST https://api.reefapi.com/danawa/v1/price_history` 순서로 요청한다. 외부 본문은 `{ "product_id": "상품 코드" }`다. Reef 키는 Node에서만 사용한다.
- 공유 Firestore 캐시는 6시간이다. 최초/만료 요청은 기존 분산 임대·비동기 수집·재시도·공개 작업 상태 경로를 이용한다. 같은 상품 상세를 반복 방문해도 유효 캐시를 재사용한다.
- 문서에 명시된 응답은 `product.product_id`, `currency=KRW`, `weekly[{date,lowest_price}]`, `monthly[{date,lowest_price}]`, `all_time_lowest`다. 이번 화면은 주간 최대 12개·월간 최대 24개 시계열만 사용한다. `all_time_lowest`를 제품 출시 이후의 확정 역대 최저가로 표시하지 않는다.
- 원본 날짜와 null 가격을 보존하고 날짜순으로 표시한다. 값이 없는 표본을 연결하거나 오늘 가격을 과거 이력에 추가하지 않는다. 빈 이력은 빈 상태로 표시한다. 주별/월별 전환은 받은 자료만 이용하며 추가 API 요청을 하지 않는다.
- 선택 기간 최저·최고는 반환된 유효 표본으로 계산한다. 주별·월별 값은 그 기간의 최저가이므로 오늘 카드 결제 가격·일별 평균·일별 관측과 다르다.
- 이 시계열을 `danawaObservations`나 `danawaDailyQuotes`에 저장하지 않으며, 구매 판단에 사용할 일별 관측 수를 늘리지 않는다.
- 상세를 처음 여는 시점에 별도 Reef 가격 이력 호출이 발생할 수 있다. 유료 호출 실행은 사용자가 한다.

## 리뷰 AI 요약 — 본문 제공 여부에 따른 표시

현재 연결된 Reef 다나와 API는 리뷰 평점·개수만 제공하고 본문은 제공하지 않는다. 리뷰 입력란과 수동 요약 버튼을 제거하고 다음 안내와 해당 상품의 다나와 원본 링크를 표시한다.

> 현재 Reef 다나와 API는 리뷰 본문을 제공하지 않습니다. 직접 확인해주세요.

본문이 없으므로 상세 진입 시 리뷰 수집이나 Gemini 리뷰 요약을 요청하지 않는다. 평점·개수·상품 스펙으로 리뷰를 추측하지 않는다. 가격 흐름은 기존과 동일하게 동작한다.

현재 실제 상품 연결 공급자는 Reef 다나와뿐이므로 자동으로 분석할 리뷰 본문이 없다. 향후 본문을 제공하는 공급자가 연결되면 상품·옵션 일치를 확인한 실제 리뷰만 AI 요약에 전달해야 한다. 기존 수동 입력용 백엔드 요약 API는 화면에서 호출하지 않으며, 자동 공급자 연결 완료를 의미하지 않는다.

## 사용자 실행 순서

추가 패키지나 Firestore 인덱스는 필요하지 않다. 기존 Firebase·Reef·Gemini 설정을 유지하고 Node, FastAPI, Spring Boot, 프론트엔드를 재시작한다. 새 리뷰 화면도 로그인 후 같은 사이트의 API를 이용한다.

1. 상품 상세에 진입하여 가격 흐름이 로딩 후 표시되는지 확인한다. 첫 수집은 작업 상태를 조회하면서 기다린다.
2. 주별·월별 전환 시 Network에 추가 price_history POST가 없는지, ‘기간별 가격 보기’ 값과 차트가 일치하는지 확인한다.
3. 실제 응답에 값이 없는 상품·최근 등록 상품에서 빈 화면 안내와 짧은 이력이 정상인지 확인한다.
4. 같은 상품을 다시 열고 운영 지표의 Node `byAction.price_history` 호출 횟수가 유효 캐시 동안 증가하지 않는지 확인한다.
5. 로그인 여부와 관계없이 가격 흐름과 리뷰 본문 미제공 안내가 표시되는지 확인한다.
6. 리뷰 입력란·수동 요약 버튼이 없는지, 상세 진입 시 리뷰 요약 요청이 발생하지 않는지 확인한다.
7. 다나와에서 리뷰 확인 링크가 선택한 상품 코드의 원본 페이지를 새 탭으로 여는지 확인한다.

아래 명령은 사용자가 각 폴더에서 직접 실행한다.

```powershell
cd D:\github\codyssey_final\backend\collector
npm test

cd D:\github\codyssey_final\backend\api
mvn test

cd D:\github\codyssey_final\backend\ai
# 기존에 사용하는 가상환경을 활성화한 뒤
python -m unittest discover -s tests

cd D:\github\codyssey_final\frontend
npm run build
```

테스트 소스는 HTTP/모델 전송을 모킹한다. 이번 변경에서 서비스 실행·빌드·테스트·실제 유료 API 호출은 하지 않았다. 문서 필드에 맞춰 구현했으며 실제 Reef 응답과 실제 Gemini 모델 지원 여부는 사용자 환경 검증이 필요하다.
