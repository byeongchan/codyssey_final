# DB 조회와 명시적 가격 갱신

검색 결과, 상품 상세, 판매처 페이지, 주·월간 가격 이력은 Firestore에 저장합니다. 기본 최신성 기준은 모두 86400초(1일)입니다. 기준이 지나도 데이터는 유지하며 열람·브라우저 새로고침으로 재수집하지 않습니다. 미저장 검색 조건이나 상품·판매처 페이지·가격 이력만 최초 수집합니다.

## 실행 전 설정

기존 `backend/api/.env`에 아래 값이 있으면 변경하세요. 기존 환경변수는 기본값보다 우선합니다. 실제 키 파일은 수정하지 않았습니다.

```dotenv
LIVE_SEARCH_CACHE_SECONDS=86400
LIVE_PRODUCT_CACHE_SECONDS=86400
LIVE_OFFERS_CACHE_SECONDS=86400
```

가격 이력은 현재 판매처 자료와 같은 최신성 설정을 사용합니다. 기존 `LIVE_REFRESH_ENABLED`, `LIVE_REFRESH_MILLIS` 설정에 따른 자동 갱신 빈은 더 이상 등록되지 않습니다.

각 서버 터미널에서 실행 중인 서버를 종료한 뒤 Spring 설정을 다시 불러오고 실행하세요.

```powershell
cd E:\github\codyssey_final\backend\api
& ..\..\scripts\Import-Env.ps1 -Path .env
mvn spring-boot:run
```

프론트엔드는 기존 `npm run dev`로 실행하고 브라우저를 새로고침합니다. 이번 변경에 FastAPI·Node 설정 변경은 없습니다.

## 동작

- 상세의 **최신 가격 갱신**: 상품 상세·판매처 첫 페이지·가격 이력을 각각 갱신합니다. Reef 요청 여러 건이 발생할 수 있습니다. 다른 판매처 페이지는 해당 페이지를 처음 조회할 때 수집합니다.
- 가격 흐름의 새로고침: 가격 이력만 명시적으로 갱신합니다.
- 검색 결과의 새로고침: DB 자료를 다시 읽습니다. 기존 검색 결과의 상품 구성 자체는 재수집하지 않습니다.
- `refresh=true`는 상품·판매처·가격 이력 조회에만 지원합니다. 저장 키에는 포함하지 않습니다.
- 자료별 마지막 성공 저장 후 60초 동안 재수집을 생략합니다. 진행 중인 동일 작업은 Firestore lease로 공유합니다.
- 갱신 요청은 기존 자료를 유지하면서 완료를 기다립니다. 실패하면 기존 가격을 보존합니다. 일부 갱신 성공은 각각 반영합니다.
- 서버에 새로 저장된 상품 상세 가격·사진은 검색·카테고리 표시에도 반영합니다. 옵션별 상품 ID는 서로 합치지 않습니다.
- 기존 DB 문서는 읽을 때 최신성 기한을 새 설정에 맞추고 원본 수집 시각은 보존합니다. 표시 데이터 4종의 `retireAt` 삭제 예약 필드는 조회 시 제거합니다. 외부에서 별도로 설정한 삭제 작업은 확인이 필요합니다.
- Gemini는 DB 자료를 사용하며 1일을 넘긴 가격을 유효한 최신 비교가로 취급하지 않습니다. 가격 근거가 바뀌면 기존 분석 캐시 키도 바뀝니다.

## 사용자 확인 절차

1. 저장된 상품 상세를 여러 번 열고 브라우저를 새로고침합니다. Node 수집기의 외부 요청 수가 증가하지 않는지 확인합니다.
2. 1일이 지난 저장 자료도 같은 동작인지 확인합니다. 원본 확인 시각은 바뀌면 안 됩니다.
3. **최신 가격 갱신**을 눌러 로딩과 자료별 확인 시각, 판매처 목록을 확인합니다. 재수집 성공 후 시각을 확인하되 원본이 같은 시각을 반환할 수도 있습니다.
4. 60초 이내 다시 눌러 외부 요청이 반복되지 않는지 확인합니다.
5. 두 브라우저에서 동시에 같은 자료를 갱신해 작업이 병합되는지 확인합니다.
6. 일부 수집 실패 시 다른 성공 결과는 반영하고 기존 실패 자료는 지우지 않는지 확인합니다.
7. 검색 목록으로 돌아가 상세에서 갱신한 해당 상품 ID의 표시가가 반영되는지 확인합니다.

외부 요청·갱신 검증에는 Reef 크레딧이 사용될 수 있습니다. 테스트·빌드는 사용자가 실행합니다.

```powershell
cd E:\github\codyssey_final\backend\api
mvn '-Dtest=LiveDataCacheTest' test
```

```powershell
cd E:\github\codyssey_final\frontend
npm run build
```
